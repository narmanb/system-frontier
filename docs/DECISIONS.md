# Decisions and intentional departures

The owner allows the port to differ from the HTML build where that improves the game. Every
meaningful departure is recorded here. "Legacy" means the effective v7.2.4 code (the last
override of each function; see OVERRIDE_INVENTORY.md).

| ID | Decision | Why | Revisit if |
|---|---|---|---|
| D-001 | Pin **Godot 4.7.2-stable** and the Compatibility renderer. CI verifies the SHA-512 of the editor and the export templates. | It was the latest stable 4.x patch when the port started. The Compatibility renderer covers Android, the Raspberry Pi 5 (GLES 3 fallback) and Web. | A newer 4.7.x patch fixes something we hit. |
| D-002 | `project.godot` lives at the repo root. | Keeps the CI and local commands identical. | — |
| D-003 | Gameplay runs as plain GDScript objects (`SimWorld`, `SimShip`, `NpcAI`) with explicit vector integration on a fixed 60 Hz `_physics_process`. It doesn't use `RigidBody2D`. Rendering happens in one `_draw()` view. | Reproduces the legacy inertia/thrust/turn model exactly (fixture-verified), keeps the simulation testable headlessly, and makes the frame rate irrelevant. Legacy capped dt at 0.033 per frame, and a fixed tick is stricter than that. | Entity counts grow enough to need node-based culling. |
| D-004 | AI distance and steering use **raw** (unwrapped) coordinates, as legacy does. Only rendering and radar use wrapped offsets. | Parity. Changing it alters how chases play out near the world edges. | It's a good candidate for a later gameplay improvement (wrap-aware pursuit). |
| D-005 | The logical canvas is **960×540 in landscape and 540×960 in portrait**. It switches automatically, and orientation is never forced. | Legacy used the same pair of canvases. Without this, portrait UI was unreadably small on phones. | — |
| D-006 | Touch buttons are sized in **millimetres** from the screen DPI (with clamps) instead of as a fraction of the canvas. | Keeps thumb targets about 14–17 mm on high-density phones. Legacy fractions produced small buttons. | Players find the defaults too large or too small. A size setting can be added. |
| D-007 | NPC faction recolor applies the **v7.2.4 material palette to the original art** and skips the v6.9 ramp pre-pass. The exact legacy chain is still implemented and fixture-tested (`recolor_grid(..., true)`). It's switchable with `FactionPalette.USE_LEGACY_V69_PREPASS`. | In legacy, blue-ish v6.9 ramps (Knights, Renegades) set off v7.2.4's cockpit mask, so those hulls turned almost entirely cockpit-blue. That defeated v7.2.4's stated goal of distinct faction identities. | The owner prefers the legacy look. |
| D-008 | Turning accepts an **analogue** axis (gamepad stick). Keyboard and touch still give full ±1 turning. | Adds controller support without changing the keyboard feel. | — |
| D-009 | No brake action. The Down arrow is unbound. **W** was added as a thrust alias next to ↑. | The owner removed Brake earlier. Legacy's final `update()` ignores ArrowDown. W is purely additive. | — |
| D-010 | The game **pauses automatically on focus loss or app backgrounding**, and all held inputs are released. Android Back opens pause, and pressing Back again from pause quits to the menu. | Milestone 5 asks for safe pausing, and this prevents stuck touch inputs. | — |
| D-011 | Transient messages sit at the bottom centre instead of the top. | They overlapped the status panel on narrow screens. | — |
| D-012 | The legacy HTML, the ship and effect art, and the superseded starter art (`legacy/unused_art/`) are **committed**. Each has a provenance entry in `assets/manifest.json`. | The art is owner-supplied from earlier sessions, and future sessions need the reference to regenerate fixtures. **The owner should confirm publishing rights**, especially for the black-hole GIF, which legacy code describes as "uploaded". If any item shouldn't be public, remove it and keep only its hash. | The owner says otherwise. |
| D-013 | (Superseded) Milestone 2 has since ported the campaign, saves, every mission family, hazards, defenders, boss, black hole, ambulance and upgrades. The Ship Factory is next. | — | — |
| D-014 | Legacy quirks kept as-is for now: an unknown module id (e.g. starter hulls' `scanner:"advanced"`) falls back to the slot's first module (`standard`). `missileBonus` is computed but never consumed. A campaign starts with 5 missiles. | Parity. They're logged so the owner can decide. | Balancing pass. |
| D-015 | The sandbox uses legacy "normal directory" spawn rules at a chosen threat (default 3). It has 6 icons and 3+threat fuel cells, and the player belongs to the Avengers, with relations seeded from the Avengers' faction bias. | It stands in for a directory until the campaign arrives. | Milestone 2. |
| D-016 | Synthesised beeps are rendered once into cached `AudioStreamWAV`s (square, sawtooth, sine, triangle with exponential decay). | Native replacement for Web Audio oscillators, with no audio asset files. | Real SFX are added. |
| D-017 | **Windows 95 look** on menus and dialogs: teal desktop, captioned windows, bevelled grey buttons, sunken white fields, tooltip-yellow messages. It's drawn procedurally (`Win95`, `TitleBar`) with no skin or font assets. **In flight there's no title bar or status bar** (owner feedback). The HUD is a compact status window (label · bar · value per row, including **Speed**; credits in the caption), a top-centre chip bar (icons collected/total, missiles, warrant, and a small pause button), and a radar window. Pause, zoom and the tactical map are in the pause menu, opened with Back, Esc, Start or the pause chip. | Owner direction: keep the legacy Win95 identity but keep the play area clear. | Owner feedback on device. |
| D-018 | Port addition: when the exit gate is open and off-screen, an arrow at the screen edge points toward it. | Replaces the removed objective status bar with something more useful. | — |
| D-019 | The radar is a **draggable, minimizable window** (drag by its caption; minimize to just the caption). Tapping the radar opens the tactical map, and tapping the map closes it. The MAP touch button was removed. Gamepad Back/Select and the M key still toggle the map. Position and minimized state persist. HUD widgets read raw touch events so they work while another finger is holding a flight pad. | Owner request. | — |
| D-020 | Touch pads are about 11–13 mm, slightly translucent, and scaled down automatically if the turn cluster and the fire/thrust cluster would overlap. This supersedes the 14–17 mm sizes in D-006. | Owner: the pads were too big and overlapped in portrait. | Device feedback. |
| D-021 | Race and boss directories don't spawn icons. | Legacy spawned icons and their defenders in those directories, then cleared the icons straight away, so every defender "joined your escort" at once. | — |
| D-022 | Dragon "Fight" uses `weaponPower` where legacy used the removed v5 `laser` stat. | In v6, legacy computed NaN hull here, which broke the HUD and made the player effectively unkillable. | — |
| D-023 | The strategy autopilot burns fuel while thrusting and turns at the ship's real turn rate. | Legacy steering used a default turn rate and never spent fuel in strategy mode. | Owner wants pure legacy behaviour. |
| D-024 | When starting an operation you can pick the faction's built-in ship (as in legacy), **plus the five starter hulls** and any saved custom ships. | In legacy the starters were only reachable through the Factory. This makes them usable before the native Factory exists. | — |
| D-025 | CUSTOM drives use **typed folder names**; nothing on the device is read. | Legacy used a browser folder picker that read file names only. Typing avoids Android storage permissions entirely. | Add a native picker later if wanted. |
| D-026 | Losing a directory offers "Directory Map" (keeps in-run earnings, relations and warrant, which is what legacy did by keeping them in memory) or "Restore Save" (discards the run). Retreating from the pause menu also keeps earnings. | Matches legacy outcomes with explicit saves. | Balancing. |
| D-027 | Saves are versioned JSON files in `user://` (campaign, ships, draft and recent colours kept separate), written atomically with a `.bak` fallback. Legacy browser saves can be imported by copying their JSON to the clipboard (Options → Import). | A native app can't read browser localStorage. | — |
| D-028 | Not ported, because the effective legacy build doesn't draw them: the v6.4 themed backgrounds and decor. The v7.2.1/v7.2.2 starfield replaced the themed background, so themes only affect names and salvage bonuses, as in legacy. | Parity. | It could be restored as an improvement. |
| D-029 | Factory adds **Fill** (4-connected, honours mirror) and **Pick** (eyedropper) tools. Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y work on desktop. | Common pixel-editor tools; purely additive. | — |
| D-030 | Ship import/export goes through the **clipboard** (JSON) instead of file download/upload. | Works the same on Android, Windows, the Pi and the web without file-permission handling. | Add native file dialogs later if wanted. |
| D-031 | The precision pad is simplified to a trackpad that moves the cursor one cell per ~8 px, plus Dab and Centre. Legacy also had auto-draw, hold-to-draw, a fine mode and a speed slider. | Covers the core use (exact pixels on a phone). Pinch-zoom up to 6× also helps. | Owner wants the full legacy pad. |
| D-032 | "Use in Current Operation" (Factory → Library) assigns the design to the saved campaign. Upgrades and components stay installed. | Legacy only let custom ships be chosen when starting a new operation. | — |
| D-033 | Factory tabs: Paint, Hull, Engines, Hardpoints, Stats, Modules, Telemetry, Library and Test. In landscape the canvas sits beside the panels; in portrait the panels scroll below it. | The legacy layout was a long page that was cramped on phones. | Device feedback. |
| D-034 | **Builds:** pushes build only the Android debug APK. It's published as a plain `.apk` on the `dev-latest` pre-release (fixed link, replaced on each build). Windows, Linux and Web builds happen only on manual "platforms: all" or on version tags. The Linux x86_64 build is still made internally so CI can smoke-run the game. | Owner tests on an Android phone and a Retroid Pocket 5 (Android). Zipped artifacts were inconvenient. | — |
| D-035 | With Touch pads set to "auto", the on-screen pads hide after gamepad input and come back on the next screen touch. | The Retroid Pocket 5 has built-in controls and a touchscreen. | — |
